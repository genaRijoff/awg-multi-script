# Тексты релизов для Telegram

Готовые к публикации посты для [@awgToolza](https://t.me/awgToolza). Здесь они лежат,
чтобы не собирать их заново к каждому релизу и чтобы формулировки не расходились с
[CHANGELOG](../../CHANGELOG.md).

## Файлы

| Файл | Что это |
|---|---|
| `vX.Y.Z-short.txt` | короткий пост: 3 пункта, до 900 символов |
| `vX.Y.Z-full.txt` | дайджест за несколько версий, до 4096 символов |

## Правила формата

- **Лимит Telegram — 4096 символов** на сообщение. Проверять до публикации:
  `wc -m docs/releases/*.txt`
- **Обычный текст, без разметки.** Никаких таблиц и markdown: то, что не понимает
  клиент Telegram, останется на экране как есть. Жирный шрифт — руками при вставке.
- **Пишем, что ломалось у пользователя**, а не имена функций: по посту должно быть
  понятно, надо ли обновляться и что проверить у себя.
- Команды — отдельной строкой, чтобы их можно было оформить как `code` при вставке.

## Чего в посте быть не должно

Кнопка «Обновить скрипт» находит новую версию только у тех, кто уже на **v0.7.10+**:
у более старых установок источник обновлений указывает на апстрим, и новую версию они
не увидят. Если аудитория такая — в пост добавляется прямая команда установки.
